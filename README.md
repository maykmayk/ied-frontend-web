# IED Milano · Frontend Web

Materiali del corso **Progettazione Multimediale 2, Unità Didattica 2 (Frontend)**
Diploma in Media Design, IED Milano, A.A. 2026/27.

Docente: Michele De Vita

Stack: React, TypeScript, Tailwind CSS 4, Zod, React Router, Vite.

## Struttura

Una cartella per lezione, ognuna un progetto Vite completo con il codice com'è a fine incontro. Ogni cartella ha il suo README con cosa abbiamo fatto, i comandi e il compito per la volta dopo.



- `lezione-01/`, `lezione-02/`, ...: un progetto Vite funzionante per incontro, aggiunto il giorno della lezione

## Uso in aula

```bash
git pull
cd lezione-XX
npm install
npm run dev
```
